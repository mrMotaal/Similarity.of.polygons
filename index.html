Geometric Similarity in Daily Life & Technology

Why do we study similarity? When two objects share the exact same shape but differ in size, mathematical similarity preserves identical angle measures and constant proportional side ratios.

§

Core Mathematical Foundation

Two necessary conditions that must both be satisfied simultaneously

1 Corresponding Angles are Congruent
$$m(\angle A) = m(\angle E),\quad m(\angle B) = m(\angle F),\quad m(\angle C) = m(\angle G),\quad m(\angle D) = m(\angle H)$$
2 Corresponding Side Lengths are Proportional
$$\frac{AB}{EF} = \frac{BC}{FG} = \frac{CD}{GH} = \frac{DA}{HE} = k$$

Idea 1: Verifying Both Similarity Conditions

Angle congruency and side length proportionality

1.1 Worked Example 1: Verifying Scaled Quadrilaterals

In the given figure, prove that polygon $ABCD \sim \text{polygon } EFGH$, and determine the similarity scale ratio of polygon $ABCD$ to polygon $EFGH$.

Solution Workspace

Model Solution:

Corresponding side ratios are all $\frac{3}{2} = 1.5$ and angles match. Hence $k = 1.5$.

1.2 Worked Example 2: Proving Similarity of Scaled Polygons

Polygon $ABCD$ and polygon $KLMN$ have right angles at $C$ and $M$ respectively. Prove $KLMN \sim ABCD$ and find their scale ratio.

Solution Workspace

Model Solution:

Side ratio $\frac{16}{24} = \frac{2}{3}$. Hence $k = \frac{2}{3}$.

1.3 Try It Yourself Verifying Proportional Polygons

Prove that polygon $ABCD \sim \text{polygon } HLKJ$ and state their similarity ratio $k$.

Solution Workspace

Model Solution:

All side ratios equal $\frac{5}{10} = 0.5$. Hence $k = 0.5$.

02

Idea 2: Finding Unknown Side Lengths & Angles

Cross-multiplication with radicals and quadrilateral interior angles

2.1 Worked Example 1: Radicals and Interior Angles

Given $ABCD \sim EFGH$, find $m(\angle C)$, $m(\angle D)$, and lengths of $DC$ and $FG$.

Solution Workspace

Model Solution:

$m(\angle C) = 45^\circ$, $m(\angle D) = 105^\circ$, $FG = 10\text{ cm}$, $DC = 30\sqrt{2}\text{ cm}$.

2.2 Worked Example 2: Angle Variables and Proportional Sides

Quadrilateral $ABCD \sim PQRS$. Given $m(\angle B) = 116^\circ, m(\angle C) = 61^\circ, m(\angle R) = (y - 73)^\circ$, find $y$ and $x$.

Solution Workspace

Model Solution:

$y = 134$ and $x = 6\text{ cm}$.

2.3 Try It Yourself Scale Factor & Side Computations

Polygon $ABCD \sim EFGH$ with $k = \frac{3}{2}$. Find angles and side lengths.

Solution Workspace

Model Solution:

$m(\angle C) = 135^\circ$, $m(\angle D) = 62^\circ$, $AD = 6\sqrt{3}\text{ cm}$, $FG = \frac{32\sqrt{2}}{3}\text{ cm}$.

03

Idea 3: Special Quadrilateral Conditions

Necessary and sufficient criteria for specific polygons

3.1 Worked Example 1: Rectangle Dimension Proportionality

Rectangle $ABCD$ has length $6\text{ cm}$ and width $4\text{ cm}$. Rectangle $XYZM$ has length $3\text{ cm}$ and width $2\text{ cm}$. Prove similarity and scale factor.

Solution Workspace

Model Solution:

All angles are $90^\circ$ and ratio $\frac{6}{3} = \frac{4}{2} = 2$. Hence $k = 2$.

3.2 Worked Example 2: Rhombus Similarity Evaluation

Rhombus $ABCD$ side $3\text{ cm}, m(\angle D) = 110^\circ$. Rhombus $EFGH$ side $5\text{ cm}, m(\angle G) = 70^\circ$. Prove similarity.

Solution Workspace

Model Solution:

$m(\angle C) = 180^\circ - 110^\circ = 70^\circ$. Scale factor $k = \frac{3}{5}$.

3.3 Try It Yourself Parallelogram Similarity Criteria

Parallelogram $ABCD$ ($AB = 8, BC = 6, m(\angle B) = 120^\circ$) and Parallelogram $PQRS$ ($PQ = 6, QR = 4.5, m(\angle P) = 60^\circ$). Prove similarity.

Solution Workspace

Model Solution:

$m(\angle A) = 60^\circ$, matching $m(\angle P) = 60^\circ$. Scale factor $k = \frac{4}{3}$.

04

Idea 4: Perimeter Ratios & Algebraic Expressions

Solving for variables $x, y, z$ using perimeter ratio invariant $k$

4.1 Worked Example 1: Algebraic Variables with Scale Ratio 3 : 2

Polygon $ABCD \sim EFGH$ with perimeter ratio $\frac{3}{2}$. Find $x, y, z$.

Solution Workspace

Model Solution:

$z = 4$, $y = 4.5$, $x = 4$.

4.2 Worked Example 2: Determining Polygon Side Lengths via Given Perimeter

Pentagon sides: $3, 5, 6, 8, 10\text{ cm}$. Second polygon perimeter $80\text{ cm}$. Find side lengths.

Solution Workspace

Model Solution:

$k = 2.5$. Sides: $7.5, 12.5, 15, 20, 25\text{ cm}$.

4.3 Try It Yourself Multi-Variable Algebraic System with Ratio 3 : 4

Polygon $ABCD \sim EFGH$ with perimeter ratio $\frac{3}{4}$. Find $x, y, z$.

Solution Workspace

Model Solution:

$z = 4.5$, $x = 2$, $y = 3$.
